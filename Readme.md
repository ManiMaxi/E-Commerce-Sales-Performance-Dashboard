#### **E-Commerce Sales Performance Dashboard | Power BI**



##### **Project Overview**

&#x09;This project focuses on analyzing e-commerce business performance using Microsoft Power BI. It provides insights into sales, profitability, product performance, and sales target achievement through interactive dashboards and visualizations.



&#x09;The objective is to convert business data into meaningful insights that support data-driven decision-making.



##### **Tools \& Technologies**

* Microsoft Power BI Desktop
* DAX (Data Analysis Expressions)
* Data Modeling
* Data Visualization



##### **Dataset \& Data Model**

&#x09;The project includes the following tables:

* Sales
* Customers
* Products
* Returns
* Targets
* DimDate
* DimState



&#x09;A dedicated Date table was created to support time-based analysis using Year, Quarter, Month, and Month Number.
